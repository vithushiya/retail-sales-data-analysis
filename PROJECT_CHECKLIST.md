- [ ] Run `python src/analysis.py` successfully.

- [ ] Open the SQL file and understand each query.
- [ ] Write your own 3–5 findings based on the outputs.

- [ ] Be ready to explain the cleaning steps, KPIs, charts, and limitations in an interview.
